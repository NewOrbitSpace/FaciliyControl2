2. Required Software

Some software components need to be installed before using this instrument driver. The minimum versions of these components are listed below, and can be downloaded from the National Instruments Download Site.

LabView 2016 or later.
VISA 2016 or later

Refer to the LabVIEW Help for more information about software requirements. You access the LabVIEW Help by selecting Help»LabVIEW Help.
